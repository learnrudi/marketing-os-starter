# Source Material

Preserve original human-facing inputs here before normalization: notes, exported documents, briefs, research, screenshots, and approved reference material.

- Preserve the original file when converting it to Markdown, JSON, CSV, SVG, or HTML.
- Use descriptive filenames.
- Record the source in the relevant research, evidence, or campaign file.
- Do not place credentials, secrets, or unnecessary sensitive information here.

This product scaffold intentionally ships without client or engagement source material.
