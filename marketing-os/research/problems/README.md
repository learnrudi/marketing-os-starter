# Market and Customer Problems

Create one Markdown record per distinct problem using `../../templates/problem-record.md`.

Use these statuses:

- `Hypothesis` — plausible but not yet supported.
- `Supported` — credible evidence exists, but important questions remain.
- `Validated` — multiple credible sources or direct customer evidence support the problem and a human has accepted the conclusion.
- `Rejected` — available evidence does not support the hypothesis.

Do not merge different audiences or situations into one broad problem. Link personas and offers only when those files exist; otherwise preserve them as open hypotheses.
