# Canonical Brand Assets

Store only official identity assets here.

- `logos/` — approved logo files and lockups.
- `fonts/` — licensed brand fonts or documented access instructions.
- `icons/` — canonical brand or product icons.

These files define the identity itself. Campaign photography, recordings, social graphics, and copy belong in a campaign first or in the shared content library after approval.

Do not recreate a missing logo or font. Record its approved source and obtain the canonical file.
